# Журнал использования токенов

Оркестратор текущей сессии не возвращает счётчики `input_tokens` и
`output_tokens` ни для главного агента, ни для дочернего потока. Поэтому точные
значения ниже отмечены как недоступные; оценки не подставляются, чтобы не
выдавать приблизительные числа за фактические. Журнал обновляется при каждой
проверке рабочего агента и будет дополнен точными значениями, если оркестратор
начнёт их публиковать.
